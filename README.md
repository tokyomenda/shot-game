# ХАЛУУН ХӨЗӨР

Бие даасан, 2–10 тоглогчтой үдэшлэгийн хөзрийн тоглоом. Next.js, TypeScript, React болон CSS ашиглав.

## Ажиллуулах

```sh
npm install
npm run dev
```

http://localhost:3000 хаягийг нээнэ.

```sh
npm run typecheck
npm run build
npm start
```

48 монгол карт `src/data/cards.ts` файлд бий. Бүх картыг хэрэглэсний дараа багцыг дахин холино. Тоглогчид, ээлж болон шийтгэлийг зөвхөн тухайн хуудасны санах ойд хадгална. Хуудсыг шинэчилбэл тоглоом эхнээсээ эхэлнэ. Серверийн өгөгдлийн сан, бүртгэл, сүлжээний олон тоглогчийн горим ашиглахгүй.

Google Fonts холбогдохгүй үед системийн Arial үсгийн хэвийг ашиглана.
